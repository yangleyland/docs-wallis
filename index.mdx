# ROOT VERSION 11 — MAPLE THEME

If you are seeing **ROOT VERSION 11** on the maple theme layout, the site is serving build 11.

Builds 5 through 10 use the mint theme. This build switches docsConfig.theme itself, not just colors — the whole layout engine changes.
